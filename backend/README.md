## Lint

このプロジェクトではコードスタイルチェックに [RuboCop](https://github.com/rails/rubocop-rails-omakase) を使用しています。CIでも自動実行されます。

```sh
bin/rubocop      # オフェンスをチェック
bin/rubocop -A   # オフェンスを自動修正
```
